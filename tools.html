QSAR Models & Computational Tools

NIK-Predict

NF-κB Inducing Kinase (NIK / MAP3K14) Bioactivity Prediction Platform

Consensus 3-run Monte Carlo 2D-QSAR model developed within the CORALSEA-2024 platform for rapid, reliable virtual screening of small-molecule NIK inhibitors. Available as a standalone offline desktop application for Windows.

Input Format: SMILES strings (Single molecule or Multi-line batch)
Output Endpoints: Predicted pIC50, IC50 (nM/µM), AD evaluation, CSV export
Validation Metrics: R² = 0.765, Q² = 0.660, CCC = 0.861, MAE = 0.291
Applicability Domain: Defect(SMILES) < 7.98
Dataset Curation: 118 small-molecule NIK inhibitors from published literature
Model Development & Tool Design: Anjali Sharma, Saurabh Gupta
Platform Overview →
Supported OS: Windows 10 / 11 (64-bit standalone executable, portable, no Python or external libraries required).

p38α/β-Predict

p38 MAP Kinase α & β Isoform Selectivity & Potency Platform

Consensus 3-run Monte Carlo 2D-QSAR ensemble model predicting continuous inhibitory potency (pIC50) against p38α (MAPK14) alongside qualitative classification on p38β (MAPK11) to establish isoform selectivity for inflammatory therapeutic design.

Input Format: SMILES strings / Chemical structures
Output Endpoints: p38α pIC50 continuous + p38β binary score (Active/Inactive)
p38α Validation: R² = 0.871, Q² = 0.859, CCC = 0.932, RMSE = 0.295
p38β Validation: Accuracy = 1.000, Sensitivity = 1.000, Specificity = 1.000
Published Citation: J. Mol. Graph. Model. 143, 109246 (2026)
Read Article in JMGM →
Model Lead: Mr. Saurabh Gupta & Prof. Yogita Bansal.
